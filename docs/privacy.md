# Privacy and publication guide

This starter kit is intentionally neutral. Your filled-in control center is not automatically safe to publish.

## Keep private

- Credentials, tokens, API keys, and local environment files.
- Personal local paths, account identifiers, and client or employer information.
- Financial, medical, legal, or other sensitive records.
- Task transcripts and temporary status that reveal private work.

## Before making a repository public

1. Inspect every tracked file, including hidden files.
2. Inspect Git history; deleting a secret from the current tree does not remove it from earlier commits.
3. Replace real examples with fictional ones.
4. Add an explicit license.
5. Confirm you can explain the purpose and audience of the repository.

## A useful boundary

Publish the starter kit if it is a general tool. Keep your filled-in personal control center private unless it has been deliberately sanitized into a separate example.

# Studio architecture

## Ownership

Atlas owns its application work. Field Notes owns its editorial work. The studio control center only routes into either one.

## Temporary state

Atlas currently has a resume point, so it owns a `CURRENT.md`. Field Notes does not need one; its current plan is clear from its README. Temporary state is optional, not a mandatory ceremony.

## Publishing

This example contains only fictional project names and relative paths. A real filled-in control center remains private unless deliberately sanitized.
